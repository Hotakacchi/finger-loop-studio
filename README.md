# Finger Loop Studio

カメラで指先を追い、空中に描いた線で音楽を作る Windows アプリです。マウスやタッチでも演奏できます。

## 使い方

Windows x64 用のポータブル版を [Releases](https://github.com/Hotakacchi/finger-loop-studio/releases/latest) からダウンロードして起動します。インストーラーは不要です。カメラを使うときは「カメラを使う」を押し、親指と人差し指をつまんで線を描きます。再生ボタンを押すと、線の高さに応じた音が鳴ります。

- 作品はアプリ内に自動保存され、JSON ファイルとして保存・読み込みもできます。
- WAV で音声を書き出せます。音色、キー、スケール、テンポ、音量、ループの長さを変更できます。
- 指の認識モデルとライブラリはネットワークから読み込むため、カメラ機能にはインターネット接続が必要です。カメラ映像は端末内で処理されます。
- 音声と保存データはデスクトップ版と Web 版で別々に管理されます。移動するには JSON を書き出して読み込んでください。
- Windows のカメラのプライバシー設定が無効な場合は、デスクトップアプリのカメラアクセスを許可してください。

## 開発

Node.js と npm を用意し、以下を実行します。

```sh
npm ci
npm start
npm run dist
```

`release/` にインストーラー不要の Windows x64 用 exe が作成されます。アプリはローカルの `127.0.0.1:49185` を使用します。別のアプリが使用中の場合は起動できません。
