# Finger Loop Studio

カメラで指先を追い、空中に描いた線で音楽を作る Windows アプリです。マウスやタッチでも演奏できます。

## 使い方

Windows x64 用のポータブル版を [Releases](https://github.com/Hotakacchi/finger-loop-studio/releases/latest) からダウンロードして起動します。インストーラーは不要です。カメラを使うときは「カメラを使う」を押し、親指と人差し指をつまんで線を描きます。再生ボタンを押すと、線の高さに応じた音が鳴ります。

- 作品はアプリ内に自動保存され、JSON ファイルとして保存・読み込みもできます。
- 線に再生位置が重なっている間、音が連続して鳴ります。WAV で音声を書き出せます。音色、キー、スケール、テンポ、音量、ループの長さを変更できます。
- 手の認識モデルとライブラリはアプリに同梱されています。カメラを含む機能はオフラインで利用でき、映像は端末内で処理されます。
- 音声と保存データはデスクトップ版と Web 版で別々に管理されます。移動するには JSON を書き出して読み込んでください。
- Windows のカメラのプライバシー設定が無効な場合は、デスクトップアプリのカメラアクセスを許可してください。
- Mac 版は Apple Silicon（M シリーズ）用の ZIP です。ZIP を展開してアプリを起動してください。アドホック署名を付けていますが、Apple の Developer ID 署名や公証はないため、macOS が起動を制限する場合があります。

## 開発

Node.js と npm を用意し、以下を実行します。

```sh
npm ci
npm start
npm run dist
```

`release/` にインストーラー不要の Windows x64 用 exe が作成されます。Mac 上では `npm run dist:mac` で Mac 版を作れます。ビルド時は npm の依存関係と手の認識モデルの取得にインターネット接続が必要です。実行時は不要です。アプリはローカルの `127.0.0.1:49185` を使用します。別のアプリが使用中の場合は起動できません。

手の認識には [MediaPipe Tasks](https://github.com/google-ai-edge/mediapipe) を使用しています。MediaPipe は Apache License 2.0 で提供されています。
